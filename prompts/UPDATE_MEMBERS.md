# MEMBERを更新する

## 利用者入力欄

- 更新方法（全置換 / 追加 / 修正 / 進級 / 卒業 / OB・OGへ移動 / 削除）:
- グループ名（例: 教員、研究員、学生）:
- 役職・学年と氏名の一覧:
- 所属先（必要な場合）:
- 削除する既存項目（ある場合）:
- 並び順の希望:
- 補足:
- 本人または所属先の掲載許可確認（確認済み / 要確認）:

## Codexへの依頼

上の情報に基づき、`index.html` のMEMBERを更新してください。

1. 作業前に `AGENTS.md` と `DESIGN.md` を全文読み、現在のディレクトリ、branch、HEAD、working tree、remoteとの差分を確認し、原則として最初にfetchしてください。既存の未コミット変更を勝手に変更・破棄・commitしないでください。
2. 入力された氏名、役職、学年、グループ、所属先だけを掲載し、人物や所属を推測で追加しないでください。氏名表記や進級・卒業・OB・OG移動の扱いが不明な場合は勝手に補正せず、確認事項として報告してください。
3. 指定された更新方法の範囲だけを変更してください。全置換の指定がない限り、入力にない既存メンバーを削除しないでください。
4. 既存HTML構造とデザインを踏襲してください。メンバー更新に不要な文章、研究内容、業績、機能は変更しないでください。
5. 学生氏名、写真、進路、所属先等の個人情報は、掲載許可が「要確認」なら公開可と断定せず、利用者の確認事項として報告してください。
6. フッターの`Created with`、株式会社アカデメイアのロゴ、ロゴから`https://www.academeia15.co.jp/web-template`へのリンクを維持し、削除、非表示化、URL変更をしないでください。
7. PC幅とスマートフォン幅で、長い氏名や役職の折り返し、余白、横スクロールを確認してください。件数境界を確認し、メンバーの「もっと見る」が必要な件数では表示・操作でき、少ない件数では表示されないことと、その他の主要操作を確認してください。
8. HTMLの静的検査とブラウザのコンソールエラー確認を行ってください。
9. 検証成功後、今回の変更だけをcommitし、現在の作業branchをremoteへpushしてください。
10. 最後に、追加・修正・移動・削除した内容、テスト結果、変更ファイル、commit hash、push先、working treeとremoteの同期状態、掲載許可を含む未確認・残課題を日本語で報告してください。
